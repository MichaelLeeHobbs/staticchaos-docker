# How to Report a Bug, Typo, or Idea

Found something broken, a spelling mistake, or have a suggestion? It takes a few
seconds — **no GitHub account or tech skills needed.**

## Easiest: report it right in the game

While you're playing, just type one of these:

- `bug <what went wrong>` — something's broken or acting weird
- `typo <the mistake>` — a spelling or text error
- `idea <your suggestion>` — something you'd like to see

**Example:** `bug the sorcerer's shield never wears off`

That's it — it's saved for the staff to read. A short, specific note is plenty.

## What makes a report easy to act on

Just three things: **what happened**, **what you expected instead**, and **your
class** (if it matters).

## Want to add more detail?

Post it in **Discord**, or open an issue on **GitHub** if you happen to have an
account. For balance feedback, add your take to the balance threads there.

Thanks for helping make the game better!

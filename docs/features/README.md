# Feature specs

Approved-for-spec **feature** and **balance** requests live here, one file per GitHub issue.

- **Filename:** `<issue#>-<YYYY-MM-DD>-<slug>.md` (e.g. `42-2026-06-27-trial-progress-command.md`).
- **Template:** copy [`../issue-spec-template.md`](../issue-spec-template.md).
- **Lifecycle:** written by the issue-ops workflow once questions are resolved, then the
  maintainer reviews. On "build it" the change is implemented, tested on dev, PR'd, merged,
  deployed, and the issue is closed with a summary.

Bug and area/content specs go in [`../issues/`](../issues/). Privacy: use GitHub handles and
issue numbers only — never Discord aliases (this repo is public).
